## Why
Live: Pax's run 2 found snow in every direction it turned (x 480 to 1150, z -650 to 490) and turned north into frozen ocean again. The owner side needs a way to change the plan of a run that is under way without starting from scratch.

## What Changes
- A new startOver.run id while a run is travelling redirects it: the new direction, fresh turns, range and snow count, the same origin (redirected).
- Pax: run 3 heads west with snowTurnAfter 10 and maxDistance 2500.
